## Semantic Tic-Tac-Toe (Multi-Agent System)

This project implements a **Semantic Tic-Tac-Toe game using a Multi-Agent System (MAS)** built with **ASTRA** and **Java**. The system models autonomous agents (player, opponent, and coordinator agents) that reason, communicate, and make decisions based on shared beliefs and game state.

The project demonstrates:
- Agent-based reasoning and coordination using ASTRA
- Semantic representation of game state and actions
- Custom Java extensions integrated into ASTRA (`RandomInRange`)
- Clean Maven-based build and project structure

### Technologies Used
- Java (Maven)
- ASTRA Agent Programming Language
- Custom ASTRA Java actions
- GitHub Actions (CI)

### Key Concepts
- Multi-agent communication and interaction
- Rule-based decision making
- Separation of agent logic and environment logic
- Reproducible builds using CI pipelines
